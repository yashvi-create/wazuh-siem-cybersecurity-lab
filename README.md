# wazuh-siem-cybersecurity-lab
Cybersecurity lab using Wazuh SIEM, IPTABLES Firewall, Ubuntu Server and Kali Linux attack simulations.
**# Wazuh SIEM Cybersecurity Lab

## Project Overview

This project demonstrates the deployment and configuration of a cybersecurity laboratory environment using:

* Wazuh SIEM
* Ubuntu Server
* Kali Linux
* IPTables Firewall
* VirtualBox

The objective is to implement a security monitoring solution, configure firewall protection, perform attack simulations, and analyze security controls.

## Lab Architecture

### Components

* Wazuh Server (Ubuntu)
* Kali Linux Attacker Machine
* IPTables Firewall
* VirtualBox Virtual Environment

## Wazuh SIEM Implementation

Activities completed:

* Wazuh installation
* Wazuh Manager configuration
* Dashboard deployment
* Service verification

Evidence is available in the WAZUH folder.

## Firewall Configuration

IPTables was configured with:

* Default DROP policies
* SSH access rule
* HTTP access rule
* HTTPS access rule
* Invalid packet filtering

Evidence is available in the IPTABLES folder.

## Attack Simulation

The following reconnaissance activities were performed from Kali Linux:

* Nmap port scan
* Service enumeration
* Aggressive OS detection scan

Results demonstrated that firewall filtering reduced information disclosure and limited attack visibility.

Evidence is available in the ATTACK_SIMULATION folder.
